# Test Cases — Tech Stack Section

## F5.1 Section headline
- [ ] The tech stack section has a centered heading text (e.g. "Công nghệ sử dụng" or equivalent)
- [ ] The heading is visible at the top of the section

## F5.2 Six technology items with logo/icon + name
- [ ] 6 technology items are displayed: Next.js, Go, PostgreSQL, Tailwind CSS, GitHub Actions, Docker
- [ ] Each item shows a logo or icon representing the technology
- [ ] Each item shows the technology name text next to/below its icon

## F5.3 Responsive grid layout
- [ ] On desktop viewport (≥1024px), items are laid out in a multi-column grid (e.g. 3 columns)
- [ ] On tablet viewport (768px–1023px), the grid adjusts to fewer columns (e.g. 2 columns)
- [ ] On mobile viewport (<640px), items stack in a single column or 2 columns
- [ ] All items have consistent sizing and spacing within the grid
