# Test Cases — Hero Section

## Happy Path Scenarios

### TC-H1: Headline renders correctly
- [ ] Headline text reads "AI Team. Không cần thuê dev."
- [ ] Text is centered horizontally
- [ ] Font is large and bold
- [ ] Text size is responsive (scales down on mobile)

### TC-H2: Subheadline renders correctly
- [ ] Subheadline text (1–2 sentences explaining the platform) appears below the headline
- [ ] Text is muted color (lower opacity than headline)
- [ ] Width is max-width constrained (not full-width)

### TC-H3: Primary CTA button "Bắt đầu ngay"
- [ ] Button with text "Bắt đầu ngay" is visible
- [ ] Background is filled blue (#3B82F6)
- [ ] Button has a hover state (visual change on mouse hover)
- [ ] Button is touch-friendly size on mobile (min 44px tap target)

### TC-H4: Secondary CTA button "Xem cách hoạt động"
- [ ] Button with text "Xem cách hoạt động" is visible
- [ ] Button style is outlined (no fill, border-only)
- [ ] Button has a hover state
- [ ] Button is touch-friendly size on mobile

### TC-H5: Background styling
- [ ] Background is dark (#0a0a0f or similar dark tone)
- [ ] Background includes a blue gradient effect (dark-to-blue tint)
- [ ] Subtle glow effect is present behind the headline area

### TC-H6: Mobile responsive layout
- [ ] Content stacks vertically on mobile viewport
- [ ] Headline, subheadline, and buttons are full-width on mobile
- [ ] No horizontal scrollbar appears at any breakpoint
- [ ] Buttons are stacked vertically (not side-by-side) on narrow screens

### TC-H7: Responsive breakpoints
- [ ] Layout adapts at 640px (sm) breakpoint
- [ ] Layout adapts at 768px (md) breakpoint
- [ ] Layout adapts at 1024px (lg) breakpoint
- [ ] Layout adapts at 1280px (xl) breakpoint
