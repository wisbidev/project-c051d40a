# aiteam Landing Page

Nền tảng landing page cho aiteam - nền tảng AI tự động xây dựng phần mềm qua Telegram.

## Tech Stack

- Next.js 14 (App Router)
- Tailwind CSS
- TypeScript

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000) để xem kết quả.
